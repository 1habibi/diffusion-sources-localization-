## Независимый review и один проход исправлений

Один fresh-context reviewer проверил весь диапазон `4231308..ae629de`, дизайн,
план, 23 изменённых файла и зависимости. Критических и minor замечаний нет;
три Important воспроизведены регрессионными тестами до изменения реализации:

1. Присутствие и содержимое необязательного distance cache не участвовали в
   identity. Теперь они аутентифицируются, включая повторную проверку collector
   после расчётов; появление, исчезновение или изменение файла запрещает resume.
2. Identity не включала общие diffusion/observations/metrics/bootstrap модули.
   Теперь SHA256 охватывает все Python-файлы локального пакета, с нормализацией
   CRLF/LF. Для каждого из четырёх пропущенных модулей тест доказал запрет resume.
3. Оценка не проверяла бюджет между каскадами. Теперь общий deadline передаётся
   из select/validate/confirm в оценку, проверяется до/после каждого каскада и
   bootstrap; summary также проверяет bootstrap. При истечении лимита следующие
   каскады не обрабатываются и полный validation payload не публикуется.

## Решения в порядке принятия

Каждый пункт содержит последствия, если решение окажется неверным.

1. Native worktree-tool не работал из родительской папки, поэтому использован
   проверенный Git worktree внутри `.worktrees/`. Существующие dirty-файлы не
   тронуты. Цена ошибки: нет автоматического app-attachment этого checkout.
2. Общий venv и явный worktree `PYTHONPATH`, без переустановки пользовательского
   окружения. Цена ошибки: отсутствующая зависимость обнаружится import/tests.
3. Не менять `src` во время полного suite: старые тесты проверяют source identity
   между стадиями. Конкурентное добавление модуля однажды дало реальную ошибку;
   suite повторён без изменения источников. Цена ошибки: недостоверные тесты.
4. Вход генерации — существующий reference `config.yaml`, не отсутствующий
   `generation_config.json`. Цена ошибки: ранний отказ сверки схемы/хэшей.
5. RED для следующих зависимых модулей готовился во время suite, но `src`
   оставался неизменным; Tasks3–5 завершены только после общей полной проверки.
   Цена ошибки: поиск причины сбоя охватывает три модуля вместо одного.
6. Шестой ключ признака — `gcn_probability_x_early` по binding spec, не черновой
   синоним. Цена ошибки: старый черновой cache несовместим (реального ещё нет).
7. Хэши saved snapshot metrics тоже закреплены; доступ только после gates.
   Цена ошибки: безобидная регенерация metrics требует нового протокола/root.
8. Repeat7027/7028 сохраняются отдельными стадиями до объединённого confirm,
   чтобы restart не повторял законченные расчёты. Цена ошибки: две лишние папки.
9. После отказа Windows ACL в smoke_v1 создан новый smoke_v2, без перезаписи
   partial и с разрешённой эскалацией. Цена ошибки: дополнительная partial-папка.
10. Единственный review выполнен внутри Task8, поскольку её brief включает review,
    хотя общий цикл описывает его после task closures. Цена ошибки: последующие
    изменения только log/status не проверены независимым reviewer; поведенческие
    исправления всё равно требуют RED→GREEN и полного suite.
11. Реальный прирост/полное время не заявляем: reviewer не запускал запрещённый
    реальный fit/cache/validation. Цена ошибки: пользователь должен отдельно
    одобрить эксперимент, прежде чем полагаться на качество.
12. Colab/GPU parity не установлена локальными тестами. Цена ошибки: возможная
    device-specific проблема остановит Colab и потребует отдельной диагностики.
13. Произвольный disconnected graph вне fixed reference пилота; изоляты в pure
    feature builder покрыты. Цена ошибки: новый граф требует отдельной проверки.
14. Fingerprint всего локального Python-пакета вместо хрупкого ручного списка
    зависимостей. Цена ошибки: даже посторонний package edit требует нового root.
15. Финальный smoke выполнен в новом smoke_v3 после изменения source identity,
    не поверх smoke_v2. Цена ошибки: ещё одна маленькая папка read-only smoke;
    старые результаты сохранены, никаких моделей не заменено.
16. Перед очисткой служебной папки плана её журналы/briefs/review копируются в
    ignored `reports/verification/temporal_learned_reranker_20260929`, затем
    сверяются SHA256. Цена ошибки: дополнительное место для технического архива;
    записи сохраняются, пользовательские файлы и worktree не удаляются.

Deferred minors: нет. Принятая Temporal-v3, backup и clean thesis_report не изменены.
