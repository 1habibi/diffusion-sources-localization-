## Сейчас: только ячейки 1–3

1. Открой notebook по ссылке. Используй свежую среду выполнения, чтобы не
   остались старые импорты проекта. Выбери **GPU T4**, не TPU. Выполняй по одной
   ячейке; не используй «Выполнить всё».
2. **Ячейка 1 — Setup.** Подключи свой Google Drive, разреши доступ. Код скачивается
   в `/content/diffusion-sources`; недостающие зависимости устанавливаются в Python
   текущего kernel. Уже установленный PyTorch/CUDA не заменяется. В конце ожидается
   `device: cuda`, путь импорта `temporal_learned_cli.py` и сообщение, что setup
   не выполнял inference/cache/обучение. Если `device: cpu`, остановись и проверь GPU.
3. **Ячейка 2 — Пути и аутентификация.** Проверяются исходный граф/train и frozen
   run 7026. Ожидается `Train inputs verified; old targets unopened.`
   Исходные данные находятся на Drive в `diffusion-sources/data/facebook_main`;
   checkpoints — в `diffusion-sources/reports/runs/facebook_main_v2`.
   Новые результаты — `reports/runs/temporal_v3_learned_reranker/v1`.
4. **Ячейка 3 — Smoke.** Проверяются шесть настоящих train-каскадов, без обучения.
   В конце ожидаются `passed: true`, `n: 6`, `training_performed: false`.
   Пришли **весь вывод**, особенно `elapsed_seconds` и
   `projected_cache2160_seconds`. На этом остановись: ячейку 4 пока не запускай.

Smoke подтверждает работу pipeline, а не качество новой модели. Прогноз cache
приблизительный: включает загрузку и первый расчёт признаков; это не гарантия
времени. В каждой вычислительной стадии действует мягкий бюджет 1800 секунд,
проверяемый между операциями/каскадами, не принудительное прерывание solver.

При `gate.passed=false` нижние этапы не разрешены; не обходи проверку вручную.
При любой ошибке остановись и пришли traceback. Partial результаты не удаляй
и не перезаписывай. При несовместимости кэша нужен согласованный новый output
root, не отключение проверки хэшей или изменение старых checkpoint.

## Что означают результаты

- **F1** — баланс precision (доля верных среди найденных источников) и recall
  (доля найденных среди истинных); среднее по каскадам. Не процент полностью
  правильно решённых примеров.
- **Delta F1** — F1 learned минус F1 принятой Temporal-v3 с beta=0.5 на тех же
  примерах. Цель пилота — не менее +0.02, то есть две процентные точки шкалы F1.
- **Exact-set accuracy** — доля полностью правильно найденных множеств источников.
- **Count accuracy** — доля правильных оценок количества источников; ранжировщик
  не меняет count-head, поэтому этот показатель должен остаться прежним.
- **Gate** — заранее определённая проверка полезного прироста без существенных
  групповых ухудшений. На validation дополнительно нужен положительный нижний
  предел парного 95% bootstrap CI (интервал неопределённости разницы F1).

Это exploratory validation, не новая независимая проверка. Ни test, ни старый
holdout, ни уже открытый независимый набор этот эксперимент не использует.
Чистовик и принятая модель обновляются только после решения по реальным результатам.
