# Facebook Pilot Report

Пилот выполнен на SNAP ego-Facebook: 4 039 узлов и 88 234 неориентированных ребра.

## Конфигурация

- источники: `k = 1, 2, 3`;
- вероятность IC: `0.01`, `0.02`, `0.03`;
- шаги: 3;
- наблюдаемость: 100%, 75%, 50%;
- попарные расстояния источников: 1-2 и 3-5;
- split: 300 / 99 / 99.

## Результат генерации

- 498 принятых каскадов;
- генерация заняла около 5.7 секунды;
- итоговые архивы занимают около 1.33 МБ;
- каждый split сбалансирован по `k`;
- вероятность и наблюдаемость распределены почти равномерно;
- медианный размер истинного каскада: 17-19 узлов;
- медианный размер множества кандидатов: 12-13 узлов;
- основная причина отбраковки: менее пяти наблюдаемых кандидатов.

## Профилирование модели

Профиль использует полный Facebook-граф, 18/9/9 каскадов, hidden size 16, две эпохи.

- batch size 1: около 1.73 секунды;
- batch size 3: около 1.31 секунды;
- batch size 3 выбран безопасным CPU-значением;
- итоговая модель использует hidden size 64 и должна запускаться на GPU/Colab.

Грубая CPU-оценка полного обучения на 10 000 каскадах составляет несколько часов с учетом train/validation проходов по 100 эпохам. Поэтому основной эксперимент следует выполнять на GPU, сохраняя CPU-профиль как проверку воспроизводимости.

## Зафиксированные основные параметры

Основной датасет задается `configs/facebook_main.yaml`:

- train: 10 000;
- validation: 2 001;
- test: 2 001;
- полный цикл факторов содержит 54 комбинации, а размеры split кратны трем для точного баланса по `k`;
- ожидаемый объем NPZ-архивов: примерно 38 МБ;
- ожидаемое время генерации: несколько минут с progress bar.

Обучение задается `configs/train_facebook.yaml`. Перед основным запуском параметр `device` необходимо переключить с `cpu` на `cuda`, если доступен GPU.
