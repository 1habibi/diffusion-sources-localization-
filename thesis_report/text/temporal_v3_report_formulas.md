# Формулы и обозначения для отчёта

В пояснениях используются обычные символы, которые копируются как текст. После каждой формулы приведена строка для Word: нажать Alt + =, выбрать ввод LaTeX, вставить содержимое блока без ограждений и без знаков доллара, затем преобразовать в профессиональный вид. Поддержка и названия кнопок зависят от версии Word; сложные конструкции здесь не используются.

Формула над блоком предназначена для чтения в Markdown. Копировать в редактор Word удобнее именно строку внутри блока. Номера формул задаются при окончательном оформлении диплома, не внутри LaTeX-строк.

## Обозначения

- S — множество настоящих источников одного каскада.
- Ŝ — множество предсказанных источников.
- |S| — число элементов множества S; |Ŝ| — число предсказанных источников.
- S ∩ Ŝ — источники, найденные точно, в тех же вершинах.
- k — истинное число источников, k = |S|.
- k̂ — количество источников, предсказанное frozen count-head.
- C — множество кандидатов; в текущем протоколе |C| ≥ 5 и k̂ ∈ {1, 2, 3}, поэтому размер выбранного набора равен k̂.
- d(u, v) — длина кратчайшего пути между вершинами u и v в рёбрах.
- I(условие) — индикатор: 1, если условие выполнено, иначе 0.
- N — число оцениваемых каскадов, здесь 1998.
- M — число checkpoints, здесь 3.

## 1. Точность — precision

$$P=\frac{|S\cap\hat{S}|}{|\hat{S}|}$$

```latex
P=\frac{|S\cap\hat{S}|}{|\hat{S}|}
```

P — доля настоящих источников среди выбранных вершин. Например, если выбраны три вершины и две верны, P = 2/3. При пустом предсказании в реализации P = 0.

## 2. Полнота — recall

$$R=\frac{|S\cap\hat{S}|}{|S|}$$

```latex
R=\frac{|S\cap\hat{S}|}{|S|}
```

R — доля настоящих источников, найденных точно. Истинное множество в этой задаче не пустое.

## 3. F1 одного каскада

$$F_1=\frac{2PR}{P+R}=\frac{2|S\cap\hat{S}|}{|S|+|\hat{S}|}$$

```latex
F_1=\frac{2PR}{P+R}=\frac{2|S\cap\hat{S}|}{|S|+|\hat{S}|}
```

F₁ — гармоническое среднее точности и полноты. Если P + R = 0, F₁ = 0. Это не доля полностью верных наборов. Пример: настоящие источники {1, 2}, предсказанные {2, 3}; P = R = F₁ = 0,5, но точного совпадения набора нет.

## 4. Точное совпадение множества

$$E=I(S=\hat{S})$$

```latex
E=I(S=\hat{S})
```

E — 1 только при полном совпадении наборов. Среднее E по каскадам — Exact set accuracy.

## 5. Правильное количество

$$A_k=I(|S|=|\hat{S}|)$$

```latex
A_k=I(|S|=|\hat{S}|)
```

Aₖ показывает, правильно ли определено количество. Среднее Aₖ — Count accuracy. При S = {1, 2} и Ŝ = {2, 3} количество верное, хотя набор неверен.

## 6. Абсолютная ошибка количества

$$e_k=\left||S|-|\hat{S}|\right|$$

```latex
e_k=\left||S|-|\hat{S}|\right|
```

eₖ — разница количеств без знака. Среднее eₖ — Count MAE. Если истинных источников три, а выбрано два, ошибка равна одному источнику.

## 7. Расстояние от настоящих источников до предсказаний

$$D_{S\rightarrow\hat{S}}=\frac{1}{|S|}\sum_{u\in S}\min_{v\in\hat{S}}d(u,v)$$

```latex
D_{S\rightarrow\hat{S}}=\frac{1}{|S|}\sum_{u\in S}\min_{v\in\hat{S}}d(u,v)
```

Source-to-set distance — насколько далеко каждый настоящий источник от ближайшего предсказания. Для каждого u выбирается свой ближайший v; один v может быть ближайшим для нескольких источников. Точное попадание даёт расстояние 0. Для геометрических метрик оба набора должны быть непустыми.

## 8. Расстояние от предсказаний до настоящих источников

$$D_{\hat{S}\rightarrow S}=\frac{1}{|\hat{S}|}\sum_{v\in\hat{S}}\min_{u\in S}d(v,u)$$

```latex
D_{\hat{S}\rightarrow S}=\frac{1}{|\hat{S}|}\sum_{v\in\hat{S}}\min_{u\in S}d(v,u)
```

Set-to-source distance — насколько далеко каждая выбранная вершина от ближайшего настоящего источника.

## 9. Симметричное расстояние

$$D_{sym}=\frac{D_{S\rightarrow\hat{S}}+D_{\hat{S}\rightarrow S}}{2}$$

```latex
D_{sym}=\frac{D_{S\rightarrow\hat{S}}+D_{\hat{S}\rightarrow S}}{2}
```

Symmetric set distance объединяет оба направления. Единица измерения — ребро; меньше — лучше. Это не расстояние при оптимальном взаимно-однозначном сопоставлении.

## 10. Покрытие источников в радиусе r

$$H_r=\frac{1}{|S|}\sum_{u\in S}I\left(\min_{v\in\hat{S}}d(u,v)\le r\right)$$

```latex
H_r=\frac{1}{|S|}\sum_{u\in S}I\left(\min_{v\in\hat{S}}d(u,v)\le r\right)
```

Hᵣ — доля настоящих источников, покрытых предсказанием на расстоянии не больше r. При r = 1 получаем Hit@1-hop, при r = 2 — Hit@2-hop. Нулевое расстояние входит в оба показателя. Затем Hᵣ усредняется по каскадам, поэтому каскады с большим k не получают больший вес только из-за числа источников.

## 11. Средние значения

$$\bar{x}_j=\frac{1}{N}\sum_{i=1}^{N}x_{ij}$$

```latex
\bar{x}_j=\frac{1}{N}\sum_{i=1}^{N}x_{ij}
```

$$\bar{x}=\frac{1}{M}\sum_{j=1}^{M}\bar{x}_j$$

```latex
\bar{x}=\frac{1}{M}\sum_{j=1}^{M}\bar{x}_j
```

xᵢⱼ — показатель для каскада i и checkpoint j; x̄ⱼ — среднее одного checkpoint; x̄ — итоговое среднее трёх checkpoints. Эти правила применяются к F1 и остальным показателям. Для F1 сначала считают F₁ каждого каскада, не гармоническое среднее уже усреднённых P и R.

## 12. Разброс между checkpoints

$$SD=\sqrt{\frac{1}{M-1}\sum_{j=1}^{M}(\bar{x}_j-\bar{x})^2}$$

```latex
SD=\sqrt{\frac{1}{M-1}\sum_{j=1}^{M}(\bar{x}_j-\bar{x})^2}
```

SD — выборочное стандартное отклонение средних трёх checkpoints. Оно отличается от разброса отдельных каскадов и от bootstrap CI.

## 13. Временная поправка

$$s'_v=s_v+\beta I(v\in O_1)$$

```latex
s'_v=s_v+\beta I(v\in O_1)
```

sᵥ — исходная оценка кандидата после sigmoid, а не logit; O₁ — раннее наблюдение на шаге t₁ = 1; β = 0,5. s′ᵥ — оценка для ранжирования, не калиброванная вероятность: после прибавления она может превышать 1. Выбирается k̂ кандидатов с наибольшими s′ᵥ. При равенстве используется исходная оценка, затем идентификатор вершины; при β = 0 реализация возвращает ровно исходный набор. Веса нейросети и предсказанное количество не меняются.

## 14. Парный прирост F1

$$\delta_i=\frac{1}{M}\sum_{j=1}^{M}\left(F_{1,ij}^{T}-F_{1,ij}^{B}\right)$$

```latex
\delta_i=\frac{1}{M}\sum_{j=1}^{M}\left(F_{1,ij}^{T}-F_{1,ij}^{B}\right)
```

$$\Delta F_1=\frac{1}{N}\sum_{i=1}^{N}\delta_i$$

```latex
\Delta F_1=\frac{1}{N}\sum_{i=1}^{N}\delta_i
```

T обозначает Temporal; B — контроль Snapshot или Early-only. Сначала разницы усредняются по трём checkpoints для каждого каскада. Затем усредняются по каскадам. Bootstrap пересэмплирует эти парные разницы со стратификацией по k, 2000 повторов. Границы CI — 2,5-й и 97,5-й процентили bootstrap-оценок. Три checkpoint не заменяют N и не увеличивают N до 5994.

## 15. Ожидаемый F1 контроля Early-only

$$\mathrm{E}[F_1]=\frac{2\mathrm{E}[|S\cap\hat{S}|]}{k+\hat{k}}$$

```latex
\mathrm{E}[F_1]=\frac{2\mathrm{E}[|S\cap\hat{S}|]}{k+\hat{k}}
```

E[⋅] здесь означает математическое ожидание, не индикатор E из формулы 4. Контроль сначала заполняет k̂ мест ранними кандидатами, а при их нехватке — остальными. Внутри каждой группы выбор равномерный. Ожидаемое пересечение считается как число выделенных мест, умноженное на долю настоящих источников в соответствующей группе; пустая группа не создаёт деления на ноль. Знаменатель фиксирован для каскада, поэтому ожидание F1 вычисляется точно. Истинные источники используются только для оценки, не при выборе предсказаний.
