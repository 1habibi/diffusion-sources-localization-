## 1. Цель исследования и сравниваемые методы

Задача заключается в восстановлении множества исходных источников распространения по наблюдаемому состоянию вершин графа. Необходимо определить не только количество источников, но и их положение. Ошибка в выборе вершины может означать как выбор соседней вершины, так и выбор удалённой области графа; поэтому используются показатели точного совпадения и расстояния.

В исходном варианте Snapshot модель JointSourceCountGCN использует один поздний снимок распространения. Модель оценивает кандидатов и предсказывает число источников. Temporal сохраняет обученную модель и её предсказание количества, но изменяет ранжирование кандидатов с учётом дополнительного раннего наблюдения. К исходной оценке кандидата прибавляется β, если вершина присутствует в раннем наблюдении. В оценке β = 0,5, момент раннего наблюдения t₁ = 1. Это поправка на этапе применения модели, а не новая обученная временная нейросеть.

Третий метод, Early-only, нужен для проверки, достаточно ли одного раннего наблюдения. Он отдаёт предпочтение ранним кандидатам, но не использует оценки GCN для ранжирования. При равных оценках рассматривается равномерный выбор; ожидаемый F1 вычисляется аналитически, без зависимости от случайного порядка идентификаторов вершин. Число выбираемых источников берётся из той же обученной count-head GCN. Поэтому этот контроль не является полностью ненейросетевым методом.

Temporal и Early-only используют дополнительное раннее наблюдение, которого нет у Snapshot. Превосходство Temporal над Snapshot показывает пользу системы с этим дополнительным входом, но не изолированный эффект изменения архитектуры при одинаковой информации. Сравнение с Early-only проверяет пользу сочетания раннего наблюдения с обученными оценками кандидатов.

## 2. Протокол независимой оценки

После исследовательских экспериментов параметры и три checkpoints были зафиксированы. Затем однократно сформирован набор из 1998 новых синтетических каскадов модели Independent Cascade (IC) на прежней топологии Facebook. Seed генерации данных — 4007026; seeds обучения frozen моделей — 7026, 7027 и 7028. Каждый checkpoint оценивался на одном и том же наборе. Таким образом, объём независимого набора составляет 1998 каскадов, а не 5994 независимых примера.

| Параметр | Значение |
|---|---|
| Роль набора | Независимое подтверждение, не подбор параметров |
| Истинное число источников k | 1, 2, 3; по 666 каскадов |
| Вероятность распространения IC | 0,01; 0,02; 0,03 |
| Максимальное число шагов | 3 |
| Доли наблюдения | 1,00; 0,75; 0,50 |
| Диапазоны расстояний между источниками | 1–2 и 3–5 рёбер для применимых случаев |
| Ложноположительные наблюдения | 0 |
| Минимальное число кандидатов | 5 |
| Верхняя доля заражённых вершин | 0,5 |
| Временная поправка | β = 0,5; t₁ = 1 |
| Повторное обучение или подбор на этом наборе | Не проводились |

Пояснение таблицы: k — реальное число источников в каскаде; seed — число, задающее воспроизводимую случайность; checkpoint — сохранённые веса модели. Вероятность IC относится к передаче распространения по ребру, а доля наблюдения — к доступности наблюдения. Это разные параметры. Расстояния измеряются числом рёбер кратчайшего пути, а не географической длиной.

При генерации выполнено 8283 попытки, из них принято 1998; 6285 отклонены из-за недостаточного числа кандидатов. Результаты относятся к набору, принятому по этому заранее заданному правилу, а не ко всем возможным IC-каскадам. Источники входят в множество кандидатов по действующему протоколу задачи.

Перед оценкой набор был закрыт и снабжён manifest. Открытие выполнено после фиксации параметров. По результатам не выбирался лучший seed и не менялись β, checkpoints или состав набора. Это независимая оценка новых каскадов на известном графе; перенос на новую топологию здесь не проверяется.

## 3. Что означают показатели

Все показатели сначала вычисляются для каждого каскада, затем усредняются по каскадам и трём checkpoints. F1 вычисляется на каждом примере до усреднения: его нельзя восстановить как гармоническое среднее опубликованных средних precision и recall.

| Показатель | Простое объяснение | Что лучше |
|---|---|---|
| Precision (P, точность) | Какая доля выбранных вершин действительно является источниками | Больше, до 1 |
| Recall (R, полнота) | Какую долю настоящих источников удалось найти | Больше, до 1 |
| F1 | Баланс точности и полноты поиска источников | Больше, до 1 |
| Exact set accuracy | Доля каскадов, где весь набор найден точно, без пропусков и лишних вершин | Больше, до 1 |
| Count accuracy | Доля каскадов с правильным количеством источников, независимо от положения | Больше, до 1 |
| Count MAE | Средняя абсолютная ошибка количества источников | Меньше, минимум 0 |
| Source-to-set distance | Для каждого настоящего источника расстояние до ближайшего предсказанного; затем среднее | Меньше, минимум 0 |
| Set-to-source distance | Для каждого предсказанного источника расстояние до ближайшего настоящего; затем среднее | Меньше, минимум 0 |
| Symmetric set distance | Полусумма двух направленных расстояний | Меньше, минимум 0 |
| Hit@1-hop | Средняя доля настоящих источников с предсказанием не дальше одного ребра | Больше, до 1 |
| Hit@2-hop | То же для расстояния не больше двух рёбер | Больше, до 1 |

Пояснение: Hit@r-hop включает точные попадания. Это не точность первого кандидата в рейтинге и не доля каскадов с хотя бы одним попаданием. Расстояния используют ближайшую вершину; взаимно-однозначное сопоставление источников не требуется. Count accuracy может быть высокой даже при выборе неверных вершин. Значение F1 = 0,5237 не означает, что 52,37% наборов найдены полностью правильно: для этого служит Exact set accuracy.

SD — выборочное стандартное отклонение средних результатов трёх seeds обучения. Оно характеризует наблюдаемый разброс между checkpoints, но не является доверительным интервалом. ΔF1 — разница F1 между методами в исходной шкале 0–1. CI — доверительный интервал этой разницы, рассчитанный парным bootstrap по каскадам.

Дополнительный критерий проверял положительную нижнюю границу CI и положительные разницы к Early-only на всех seeds после прохождения основного критерия. Пояснение таблицы 5: k задаётся истинными источниками, а не предсказанием модели. При одном источнике значительная часть преимущества над Snapshot уже присутствует у Early-only. Дополнительный прирост Temporal относительно Early-only наиболее выражен при трёх источниках. Эти значения не доказывают, что задача с большим k в общем случае проще: показатели зависят от состава данных и определения F1.

Эти характеристики одинаковы для трёх checkpoints, поскольку используются одни и те же ранние маски. Они описывают доступную информацию, а не точность предсказаний Temporal.

## 7. Подписи и пояснения к графикам

### Рисунок 1 — общее качество (`01_overall_f1`)

Подпись: «Средний F1 методов на 1998 независимых каскадах. Точки — три frozen checkpoints; усы — ±1 выборочное стандартное отклонение по seeds обучения».

По оси X — методы, по оси Y — F1 от 0 до 1; больше — лучше. Самый высокий столбец у Temporal. Усы описывают разброс по seed, не 95%-й CI и не разброс всех отдельных каскадов.

### Рисунок 2 — парные разницы F1 (`02_paired_deltas`)

Подпись: «Средние разницы F1 Temporal относительно Snapshot и Early-only с 95%-ми парными bootstrap-интервалами».

По оси X — ΔF1, по оси Y — сравниваемые пары. Точка — оценка прироста, горизонтальный отрезок — CI. Пунктирная линия в нуле означает отсутствие прироста. Оба отрезка правее нуля. Интервалы условны относительно фиксированных графа, протокола и checkpoints.

### Рисунок 3 — F1 по числу источников (`03_f1_by_k`)

Подпись: «Средний F1 по истинному числу источников k; каждая группа содержит 666 каскадов».

По оси X — истинное k, по оси Y — средний F1; n под группой — число каскадов. Temporal выше обоих контролей в каждой группе. Максимальная добавка к Early-only наблюдается при k=3. Это описательный разбор, а не отдельные подтверждённые групповые гипотезы.

### Рисунок 4 — F1 по числу кандидатов (`04_f1_by_candidates`)

Подпись: «Средний F1 по размеру множества кандидатов; n — число каскадов в соответствующей группе».

По оси X — интервалы размера множества кандидатов, по оси Y — F1. Сложность выбора возрастает при большем количестве кандидатов; в этих данных качество уменьшается. Temporal сохраняет преимущество, но не устраняет проблему больших candidate sets. Метка 1–10 соответствует фактическим размерам 5–10.

### Рисунок 5 — F1 отдельных checkpoints (`05_f1_by_seed`)

Подпись: «F1 методов для frozen checkpoints с seeds обучения 7026, 7027 и 7028 на одном независимом наборе».

По оси X — seed обучения, по оси Y — F1. Во всех трёх группах преимущество Temporal сохраняется. График не означает, что проводились три независимые генерации данных, и не используется для выбора лучшего seed.

### Рисунок 6 — точность и расстояние (`06_localization`)

Подпись: «Точное совпадение набора, покрытие настоящих источников в радиусе одного и двух рёбер, точность количества и симметричное расстояние между наборами».

Левая панель: по оси X — показатели, по оси Y — проценты; больше — лучше. Здесь раздельно видны точное восстановление, приблизительная локализация и количество. Правая панель: по оси X — методы, по оси Y — среднее расстояние в рёбрах; меньше — лучше. Разные единицы не смешиваются на одной оси. Count accuracy одинакова, а точность выбора вершин и расстояние улучшились. Early-only отсутствует по причине отсутствия сохранённых геометрических оценок, а не из-за нулевого качества.

## 8. Вывод и ограничения

На 1998 новых синтетических IC-каскадах известного Facebook-графа временная поправка к frozen GCN повысила средний F1 с 0,3442 до 0,5237. Прирост к Snapshot составил 0,1796, а к контролю Early-only — 0,0889; 95%-е парные bootstrap-интервалы обеих разниц лежат выше нуля. Преимущество сохраняется для всех трёх checkpoints. Одновременно увеличились точные совпадения наборов и покрытие источников в радиусе одного ребра, а расстояние локализации уменьшилось. При этом количество предсказанных источников не изменилось.

Результат подтверждает полезность сочетания обученных оценок кандидатов с дополнительным ранним наблюдением в исследованном протоколе. Он не означает, что все источники восстанавливаются надёжно в каждом примере: полностью правильный набор получен в среднем в 22,79% случаев. Наиболее заметные оставшиеся трудности — один источник и большое множество кандидатов.

Основные ограничения: одна известная топология; синтетический IC-генератор вместо реальных наблюдений; максимум три источника; протокол наличия источников в множестве кандидатов; условные bootstrap-интервалы и только три checkpoints. Раннее наблюдение в эксперименте восстановлено по воспроизводимой симуляции. Для практического применения требуется реально доступное раннее наблюдение; его наличие нельзя считать бесплатным или гарантированным. Early-only — конкретный контроль с общей learned count-head, а не все возможные временные эвристики. Превосходство над всеми методами или перенос на другие графы не заявляется.

Открытый независимый набор следует сохранить для отчётности, но не использовать для дальнейшей настройки. Новые варианты модели требуют отдельного train/development-протокола, а их независимое подтверждение — нового заранее зафиксированного набора.
